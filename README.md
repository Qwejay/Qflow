## 📖 简介 (Introduction)

**Qflow** 是一个基于 Python 开发的轻量级、可视化节点办公自动化引擎。通过简单直观的节点拖拽与贝塞尔曲线连接，即可快速编排复杂的桌面自动化任务。

- **完全开源**：透明的逻辑实现，无后门。
- **绿色便携**：无需繁琐的数据库或服务配置，即开即用，支持 `.qflow` 项目文件双击直接关联打开。
- **隐私安全**：纯离线本地运行，不联网，不上传任何用户数据。
- **低资源占用**：无需独立显卡，普通办公电脑即可流畅运行。

## ✨ 核心功能 (Features)

### 🎨 可视化节点编排

- 支持 20 种核心节点。
- 支持方向箭头曲线与线路中继点。
- 实时坐标状态栏。
- 支持 50 步历史撤销 / 重做。

### 👁️ 视觉与多模态感知

- **智能找图**：集成 OpenCV，支持智能混合、多尺度模板匹配、AKAZE 特征匹配；支持可视化点击锚点偏移拾取及未找到时自动滚动屏幕。
- **多图检测**：支持同时检测多张参考图是否全部出现。
- **静止监控**：实时计算指定 ROI 区域像素差，判断网页或软件画面是否加载完毕并保持静止。
- **声音检测**：基于 Windows WASAPI 实时监测系统音频峰值，实现“有声音输出”或“保持静音”触发。

### 🖱️ 物理级键鼠与系统控制

- **鼠标操作**：点击（单击 / 双击、左键 / 中键 / 右键）、移动、拖拽、滚轮滚动，支持屏幕绝对坐标一键拾取。
- **键盘输入**：内置剪贴板保护粘贴模式（高速输入中文防乱码，输入后自动还原原剪贴板）与全键盘组合键发送。
- **系统协同**：支持打开程序、执行 CMD 命令、打开网页、剪贴板读写及桌面气泡通知。

- **新增**：全新深色与浅色双主题界面，支持高分屏清晰渲染，彻底解决文字发虚模糊的问题。

- **新增**：完善【分流】节点的单条件判断与多分支设置界面，以及【序列】节点的步骤数量设置。
- **新增**：节点右键菜单增加“从此节点开始测试运行”、“切换调试断点”、“断开所有连线”及多种对齐排列方式。
- **新增**：支持 `.qflow` 项目文件双击直接打开、未保存修改退出提醒，以及主题和快捷键设置自动保存。
- **优化**：屏幕找图与画面监控时自动屏蔽软件自身窗口，防止误识别到编辑器内部的截图预览。
- **优化**：大幅提升多节点同时拖拽时的流畅度，鼠标滚轮缩放优化为以当前指针位置为中心。
- **优化**：连线增加方向箭头指示；右侧属性面板修改参数后，画布上的节点内容实时同步更新。
- **修复**：修复找图组件在测试定位偏移时，未同步当前匹配算法与缩放比例导致找不到图的问题。

### [2.0.0] - 2026-06-20

- **新增**：支持导出独立 `.exe` 引导执行程序，支持无头 / 系统托盘静默运行与防多开保护。
- **新增**：【延时】组件增加“随机延时”模式，智能模拟真人操作节奏。
- **新增**：右侧属性面板在空闲状态下增加图文引导，包含对【变量】组件的用法科普。
- **优化**：重构【键盘】组件组合按键底层驱动，修复 F 区及小键盘无法触发的问题，增强文本输入粘贴模式的防乱码能力。
- **优化**：梳理【鼠标】组件的交互结构，双击操作合并至点击选项；修复定向滚动时坐标未跟随移动导致的滚动失效问题。
- **优化**：优化 AKAZE 特征识图的相似度分值映射，解决“测试能通过但实际运行失败”的严格阈值问题。
- **优化**：找图组件的“未找到尝试滚动”功能，现在会自动将鼠标移动到识别区域居中再进行滚动，防止越界失效。

### [1.7.6] - 2026-06-19

- **修复**：解决 `WindowEngine` 遍历系统进程快照时，因解码异常导致的句柄泄露问题。
- **修复**：修复图像匹配测试（TestMatch）在后台线程调用 UI 导致的偶发性闪退。
- **优化**：统一可选依赖库（如 `pyperclip`、`opencv`）的导入与检查逻辑。

### [1.7.5] - 2026-05-23

- **新增**：提示节点（`notify`）增加 `{ALL_VARS}` 宏支持，可一键打印所有内存变量供调试。
- **优化**：改用原生 `user32.GetCursorPos` 检索绝对物理坐标，解决混合 DPI 缩放下的像素偏离。

## 🎮 快速上手 (Quick Start)

### 1. 界面概览

- **顶部工具栏**：提供新建、打开、保存、另存为、撤销 / 重做、导出 EXE、清空画布、系统设置及运行 / 暂停控制。
- **左侧组件库**：按“流程控制”、“鼠标与键盘”、“应用与系统”、“图像与感知”、“变量与剪贴板”分组，支持关键词搜索与拖拽 / 双击添加。
- **中间节点画布**：核心编排区。从节点右侧端口拖出连线至下一节点左侧输入端口；底部状态栏实时显示节点统计、坐标与缩放比例。
- **右侧属性面板**：选中单个节点时编辑其详细参数；选中多个节点时提供快捷对齐与批量操作。
- **底部执行日志**：实时追踪节点执行流向、统计耗时与异常信息。

### 2. 快捷键对照表 (Shortcuts)

| 操作 | 快捷键 / 鼠标交互 |
| :--- | :--- |
| **启动流程** | `F9`（可在设置中自定义） |
| **停止 / 紧急中断** | `F10`（或将鼠标快速甩至屏幕左上角触发 FailSafe） |
| **新建 / 打开 / 保存 / 另存为** | `Ctrl+N` / `Ctrl+O` / `Ctrl+S` / `Ctrl+Shift+S` |
| **撤销 / 重做** | `Ctrl+Z` / `Ctrl+Y`（或 `Ctrl+Shift+Z`） |
| **复制 / 粘贴 / 复制并粘贴** | `Ctrl+C` / `Ctrl+V` / `Ctrl+D` |
| **全选 / 删除选中节点** | `Ctrl+A` / `Delete` |
| **画布缩放（以指针为中心）** | `鼠标滚轮` 或 `Ctrl++` / `Ctrl+-` |
| **适应画布视野 / 重置 100% 缩放** | `F` / `Ctrl+0` |
| **画布平移** | `空格 + 鼠标左键拖拽` 或 `鼠标中键 / 右键拖拽` |
| **快速搜索添加节点** | 在画布空白处 `双击鼠标左键` |
| **快速断开端口连线** | 在节点输入 / 输出端口上 `点击鼠标右键` |

### 3. 创建你的第一个自动化流程

1. **起点**：启动软件后，画布默认自带一个 `▶ 开始` 节点。
2. **找图**：从左侧拖入一个 `🎯 找图` 节点，选中后点击节点上方的 **“🎯 抓取目标”**（或右侧面板的 **“📸 截取目标图像”**），框选屏幕上的目标图标。
3. **连线**：按住 `▶ 开始` 节点右侧的输出端口，拖出曲线连接到 `🎯 找图` 节点的左侧输入端口。
4. **后续动作**：`🎯 找图` 节点默认自带“找到后单击左键”动作；你也可以继续拖入 `⌨️ 键盘` 或 `⏳ 延时` 节点，并连接到找图节点的 `找到` 端口。
5. **运行**：点击顶部工具栏的 **“▶ 运行 (F9)”**，或直接按键盘 `F9` 即可自动执行。

## ⚙️ 源码部署与安装 (Installation)

### 1. 环境准备

Windows 10 / Windows 11 系统，已安装 **Python 3.8+**。

### 2. 克隆项目

```bash
git clone https://github.com/Qwejay/Qflow.git
cd Qflow
```

### 3. 安装依赖

```bash
pip install -r requirements.txt
```

### 4. 启动程序

```bash
python main.py
```

## 📦 核心依赖说明 (Dependencies)

| 依赖库 | 主要用途 |
| :--- | :--- |
| `tkinter / ttk` | 构建原生级轻量化桌面 GUI 界面。 |
| `Pillow (PIL)` | 负责多屏图像抓取、缩略图渲染与像素差异分析。 |
| `opencv-python`、`numpy` | 提供多尺度模板匹配与 AKAZE 特征点匹配算法。 |
| `pyautogui`、`pynput` | 实现鼠标控制、键盘模拟输入与全局热键监听。 |
| `pyperclip` | 支持剪贴板读写与防乱码粘贴模式。 |
| `pycaw`、`comtypes` | 用于 Windows WASAPI 系统音频峰值监测。 |
| `pystray` | 提供导出应用无痕运行时的系统托盘图标驻留支持。 |
